# Changelog

All notable changes to Teddy Manager. Versions follow [Semantic Versioning](https://semver.org).

## 0.1.0 – first public release

- Custom tonies: learn by placing on a box, name, colour (palette or colour wheel), picture or generated coin image.
- Playlists with drag and drop, draft mode (“Load onto Tonie”), shuffle, swap, copy, even volume, sleep mode.
- Library: songs, stories (multi-part, chapters), podcasts, trimmer, unused filter, which tonies use a track.
- Radio stations and podcast subscriptions (auto-filled tonies).
- Toniebox settings per box (volume, tap, LED) with evening mode.
- Last placed figure and history from TeddyCloud's log; “box up to date?” per tonie.
- Play tonies on the phone with chapters and resume; optional kids view.
- Optional link import from YouTube / YouTube Music with search, preview, SponsorBlock and song-version detection.
- German and English UI, PWA, optional PIN, daily backups, update script, release images for amd64/arm64.
